# Welcome to merge_pob
This is a basic python project to merge multiple PoB's into one that I have been working on for the past few months as a means to not only relearn python, still needing to do more on this front, but also to fix a pet peeve of mine when content creators who use PoB dont have the PoB all in one, they like to make a load of seperated PoB's

## AI Disclosure
As much as I hate that I have used AI on this, AI was used on this project the parts it was used was:
- Minor debugging
- Creating a UI plan as I am horrible at creating UI's or just design in general

## Use
Simply boot up the project and you will have the UI appear, you create the names and add the POB code/links, hit generate and in a few seconds it will merge all of them into one, giving you a code at the end in which you can add to POB yourself

### PoB Loadouts
Note, that not all loadouts will work, while some PoBs share the same names you may find that a lot of the "Leveling" PoBs will have split trees, items and skills that aren't named the same. If you so wish to better link these together you can link these by renaming the Trees, Items and Skills and adding a {X} were X is a number - everything with {1} will match up regardless of their name and the Loadout will take the tree name i.e.
- Act 1 Tree {1}
- A1 Gear {1}
- Lvl 12 skills {1}
The drop down will show "Act 1 Tree {1}" however when you swap to the Gear Tab "A1 Gear {1}" will already be selected, same with the Skills
